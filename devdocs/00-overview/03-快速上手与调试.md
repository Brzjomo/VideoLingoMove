# 快速上手与调试

面向"第一次拿到这个仓库要把它跑起来"和"改代码时怎么验证"两类场景。

---

## 一、职责与边界

本文只讲**环境、启动、调试手法**；安装脚本逐行细节见 [`../06-batch-and-tools/02-安装脚本与依赖.md`](../06-batch-and-tools/02-安装脚本与依赖.md)，UI 操作见 [`../04-interfaces/02-Streamlit界面组件.md`](../04-interfaces/02-Streamlit界面组件.md)。

## 二、硬性前置条件

| 项 | 要求 | 为什么 |
| --- | --- | --- |
| Python | **3.10.x** | `torch-2.1.2+cu118-cp310-*.whl` 是 cp310 专用；WhisperX 3.2.0 也按此版本约束 |
| Conda | 环境名必须是 `videolingo` | `OneKeyStart.bat` / `StartBatch.bat` / `AudioExtract/Start.bat` 都硬编码 `call "%USERPROFILE%\anaconda3\Scripts\activate.bat" videolingo` |
| FFmpeg | 必须能在 PATH 找到 | 全流程约 20 处 `subprocess` 调用 `ffmpeg`；根目录自带 `ffmpeg.exe` 且 `st.py:9` 把项目根注入 PATH |
| CUDA + cuDNN | 有 N 卡则强烈建议（无 N 卡也能跑，但 GPU 被强制为 CPU，转写极慢） | `core/step2_whisperX.py:80` 依据 `torch.cuda.is_available()` 决定 device |
| 磁盘 | ≥ 30 GB 空闲 | 一个 30 分钟视频会产生 `raw.wav`(170MB) + `raw.mp3`(86MB) + `for_whisper.mp3`(65MB) + 模型缓存数 GB |
| **工作目录** | **必须是项目根目录** | 全代码使用相对路径 `output/...`、`config.yaml` |

## 三、安装

```powershell
# 1) 建环境（与 .bat 脚本保持一致）
conda create -n videolingo python=3.10.0 -y
conda activate videolingo
conda install git -y

# 2) 可选：把 torch wheel 放到项目根目录，install.py 会优先用本地文件
#    torch-2.1.2+cu118-cp310-cp310-win_amd64.whl

# 3) 安装
python install.py
```

`install.py` 的真实执行顺序（`install.py:137-231`）：

1. `install_package("requests", "rich", "ruamel.yaml")` —— 先装安装脚本自己要用的依赖。
2. `core.pypi_autochoose.main()` —— 并发测速清华镜像 vs 官方 PyPI，然后 `pip config set global.index-url <最快的>`，**会修改全局 pip 配置**（`core/pypi_autochoose.py:42-50`）。
3. `check_nvidia_gpu()` —— 用 `pynvml` 探测 GPU（没装会自动 `pip install pynvml`）。
4. 安装 torch：本地有 `torch-2.1.2+cu118-...whl` 就用本地，否则走 `--index-url https://download.pytorch.org/whl/cu118`。**注意：无 GPU 分支也走 cu118 索引**（`install.py:173-178`），并非 CPU 专用 wheel。
5. Linux 才会执行 `install_noto_font()`（`apt-get install fonts-noto` 或 `yum install google-noto*`）。
6. `pip install -r requirements.txt`。
7. `check_ffmpeg()` —— 找不到 ffmpeg 时在 Windows 上下载 BtbN 的 GPL 构建并解压到**当前工作目录**。
8. 最后 `subprocess.Popen(["streamlit", "run", "st.py"])` 自动拉起应用。

> ⚠️ `install.py` 末尾会自动启动应用（`install.py:231`），如果只想装依赖需要手动中断。

## 四、启动

| 目标 | 命令 | 说明 |
| --- | --- | --- |
| Web 交互模式 | `python -m streamlit run st.py` 或双击 `OneKeyStart.bat` | 默认 <http://localhost:8501>（`.streamlit/config.toml` 只设了 `maxUploadSize = 4096`，未改端口） |
| 批处理模式 | `cd batch && StartBatch.bat`（脚本内 `cd ..` 回到根目录后运行 `streamlit run batch\utils\gui.py`） | **同样是 Streamlit 应用**，不是桌面 GUI |
| 批量音频提取工具 | `cd AudioExtract && Start.bat` | 独立小工具 |

`st.py:8-10` 的启动期初始化很关键：

```python
current_dir = os.path.dirname(os.path.abspath(__file__))
os.environ['PATH'] += os.pathsep + current_dir   # 让 `ffmpeg` 命中根目录的 ffmpeg.exe
sys.path.append(os.path.dirname(os.path.abspath(__file__)))
```

## 五、必须配置的项目（否则跑不动）

编辑 `config.yaml`：

| 键 | 说明 |
| --- | --- |
| `api.key` / `api.base_url` / `api.model` | **真正生效的 LLM 配置**（`core/ask_gpt.py:56` 只读 `api`）。`deepseek_api` / `qwen_api` / `siliconflow_api` / `ollama_api` 是 sidebar 用来一键切换的**预设池**，它们通过 `assign_key` 写入 `api` 后才生效 |
| `whisper.language` | 源语言；`zh` 会强制使用 Belle 中文标点模型；`auto` 走自动检测 |
| `whisper.model` | 非中文时使用的模型 |
| `tts_method` + 对应引擎的 key | 配音阶段用 |
| `transcription_only` | 只要字幕不要翻译时设 `true` |

⚠️ **安全**：仓库当前 `config.yaml` 中明文存有 DeepSeek / Qwen / SiliconFlow / 火山引擎的真实密钥与 token，且 `.gitignore` **没有**忽略 `config.yaml`（已核对）。接手后第一件事建议是把密钥改为环境变量读取，并把 `config.yaml` 从版本控制中移除。详见 [`../03-subsystems/01-LLM调用与提示词.md`](../03-subsystems/01-LLM调用与提示词.md) 的「安全提醒」小节。

## 六、最小可用验证路径

不要一上来就跑完整流程。按下表逐级验证：

| 级别 | 操作 | 通过标准 |
| --- | --- | --- |
| L0 环境 | `ffmpeg -version`；`& $py -c "import torch;print(torch.cuda.is_available())"` | 有输出、`True`（有 N 卡时） |
| L1 配置 | `& $py -c "from core.config_utils import load_key; print(load_key('api'))"` | 打印出 api 字典 |
| L2 上传/下载 | UI 上传一个 < 1 分钟短视频 | `output/` 下出现视频文件，页面出现播放器 |
| L3 转写 | 只跑 step2（见下节命令） | 生成 `output/log/cleaned_chunks.xlsx`，行数 ≈ 词数 |
| L4 对齐 | 跑 step6 | `output/trans.srt` 的序号连续、时间递增 |
| L5 成片 | 侧边栏打开 **Burn-in Subtitles** 后跑 step7 | `output/output_sub.mp4` 可播放且字幕正常 |
| L6 交付 | 点「下载所有字幕」 | `output/<视频名>.srt` 与 `<视频名>.txt` 存在，zip 内 6 个条目 |

> `$py` = `"$env:USERPROFILE\anaconda3\envs\videolingo\python.exe"`（见上文的环境说明）。

## 七、单步调试（最重要的技巧）

每个 `core/stepN_*.py` 都有 `if __name__ == '__main__':` 入口，可以单独跑：

```powershell
# 必须 cd 到项目根目录
cd E:\VideoLingo\VideoLingoMove
$py = "$env:USERPROFILE\anaconda3\envs\videolingo\python.exe"
$env:PYTHONIOENCODING='utf-8'   # 避免 GBK 控制台打印 emoji 崩溃

& $py -m core.step2_whisperX              # 转写
& $py -m core.step3_1_spacy_split         # NLP 切分
& $py -m core.step3_2_splitbymeaning      # LLM 语义切分
& $py -m core.step4_1_summarize           # 术语总结
& $py -m core.step4_2_translate_all       # 翻译
& $py -m core.step5_splitforsub           # 字幕长度切分
& $py -m core.step6_generate_final_timeline  # 生成 SRT
& $py -m core.step7_merge_sub_to_vid      # 压制字幕（Burn-in 关闭时静默跳过）
```

> 💡 用 `& $py -m core.xxx` 而不是 `& $py core/xxx.py`：两者都能跑（模块内都有 `sys.path.append`），但 `-m` 形式更接近 Streamlit 的导入方式，能更早暴露 import 问题。

### 7.1 重跑某一步的通用手法

因为「存在即跳过」，想重跑必须**先删产物**：

| 想重跑 | 删除 |
| --- | --- |
| 转写 | `output/log/cleaned_chunks.xlsx` |
| NLP 切分 | `output/log/sentence_splitbynlp.txt`、`output/log/sentence_splitbymeaning.txt` |
| 翻译 | `output/log/translation_results.xlsx`（+ 必要时 `output/gpt_log/*.json`） |
| 字幕生成 | `output/*.srt`、`output/log/subtitle_stage_done.txt` |
| 压制 | `output/output_sub.mp4`（并删完成标记，否则 UI 仍显示已完成） |
| 全部 | UI 上「删除并重新选择」按钮（会 `shutil.rmtree("output")`），或手动删 `output/` |

### 7.2 清 LLM 缓存（改提示词后必做）

```powershell
Remove-Item output\gpt_log\*.json
```

`output/gpt_log/<log_title>.json` 同时是**缓存**：`ask_gpt()` 用 `(model, prompt)` 精确匹配历史记录并直接返回旧结果。改了 `core/prompts_storage.py` 却"没效果"，九成是这个原因。

> ⚠️ 历史上磁盘上可能残留一个 `output/gpt_log/None.json`——它会让「API 密钥检查」命中缓存假通过。现在 `log_title=None` 不再写该文件，遇到时直接删掉即可。

### 7.3 清火山 ASR 二级缓存（改火山参数后必做）

```powershell
Remove-Item -Recurse output\log\asr_results
```

火山路径有**第二级缓存**（`output/log/asr_results/volcano_asr_*.json`）。改了 `volcano_asr.*` 参数后，除了删 `cleaned_chunks.xlsx` 还要删这个目录，否则会命中旧结果。UI 上也提供了「清空 ASR 结果缓存」按钮（检测到缓存时出现在字幕区块下方）。

### 7.4 观察 LLM 交互

- `output/gpt_log/<log_title>.json` —— 每个 log_title 一个文件，数组结构，含 `model` / `prompt` / `response` / `message`。
- `output/gpt_log/error.json` —— 解析失败或业务校验失败的原始返回（**校验失败也会写这里**，且 `message` 是真实的业务错误，不再是误导性的 "json_repair parsing failed"）。
- log_title 与步骤对应关系见 [`../03-subsystems/01-LLM调用与提示词.md`](../03-subsystems/01-LLM调用与提示词.md)。

## 八、调试时最常用的"探针"代码

```python
# 看当前配置
from core.config_utils import load_key
print(load_key('api'), load_key('whisper.language'), load_key('tts_method'))

# 看词级时间轴
import pandas as pd; print(pd.read_excel('output/log/cleaned_chunks.xlsx').head(20))

blocks = [b for b in txt.strip().split('\n\n') if b.strip()]
```

## 九、常见现象速查（详细版见 05-guides/05）

| 现象 | 最可能原因 | 处置 |
| --- | --- | --- |
| 改了提示词但输出没变 | `output/gpt_log/*.json` 缓存命中（缓存键含 model + prompt） | 删缓存 json |
| 改了火山 ASR 参数但输出没变 | `output/log/asr_results/` 二级缓存命中 | 删该目录（或用 UI 按钮） |
| 改了参数但某步没重跑 | 该步产物已存在（幂等跳过） | 删对应产物 |
| `output/` 下有多个视频文件 | `find_video_files()` 会取最新的一个并告警 | 归档或移走多余文件 |
| 对齐报错或时间轴错乱 | `cleaned_chunks.xlsx` 文本与句子文本不一致 | 确认下游是否正确 `strip('"')`；把 `subtitle.align_on_mismatch` 设为 `strict` 可让问题立即暴露而非兜底 |
| LLM 请求全部失败 | `api.key` 为空 / base_url 拼接问题 | 见 [`../03-subsystems/01-LLM调用与提示词.md`](../03-subsystems/01-LLM调用与提示词.md) |
| 转写极慢 | 落在 CPU（无 CUDA 或驱动异常） | 看启动日志 `device: cpu` |
| 界面按钮文字看不清 | 侧边栏与主区域的按钮配色 CSS 冲突 | 见 [`../05-guides/04-已知问题与技术债.md`](../05-guides/04-已知问题与技术债.md) R4 |
| 没有成片可预览 | 侧边栏 **Burn-in Subtitles** 处于关闭状态 | 打开它并重跑 step7；纯音频输入例外（会保留黑底成片） |
| 打开页面就报 `TypeError: ... unexpected keyword argument` | streamlit 版本与代码中的控件参数名不匹配 | `pip show streamlit` 核对版本；见技术债 G4 |
