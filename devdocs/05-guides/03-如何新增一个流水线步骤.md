# 如何新增一个流水线步骤

以「在时间轴对齐后、压制前插入一步『字幕敏感词替换』」为例，给出可照做的清单。核心原则：**读上游产物、写新产物、遵守幂等约定、不破坏中间产物契约**。

---

## 一、设计前必须回答的 4 个问题

| 问题 | 为什么重要 |
| --- | --- |
| **插在哪两步之间？** | 决定输入/输出文件；同时检查你是否破坏了后面的依赖（例：若在 `step6` 之前改文本，`step6` 的逐字符匹配会失败，见 P1-3） |
| **输入是什么文件？** | 只能读上游**已经写好**的产物。对照 [`../00-overview/02-数据流与中间产物.md`](../00-overview/02-数据流与中间产物.md) |
| **输出写到哪里？** | 若是新产物 → 放 `output/log/`（结构化）或 `output/audio/`（音频）；若是**覆盖**上游产物 → 必须说明为什么不能新增文件（覆盖会破坏断点续跑） |
| **失败了怎么办？** | 现有步骤没有统一异常处理，你的步骤抛异常会直接中断整条链路。建议：可降级的操作自行 try/except 并打印告警 |

---

## 二、改动清单（5 步）

### 步骤 1：新建模块

命名规范：`core/stepN_M_功能名.py`，其中 `N` 是它前面那一步的编号，`M` 是并列序号（现有先例：`step3_1` / `step3_2`、`step8_1` / `step8_2`）。

例如插在 step6 与 step7 之间 → `core/step6_1_replace_sensitive.py`。

模块骨架（照抄现有 step 的结构）：

```python
import os, sys
sys.path.append(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
from rich import print as rprint
from core.config_utils import load_key

INPUT_FILE = 'output/trans.srt'
OUTPUT_FILE = 'output/log/sensitive_replaced.txt'

def replace_sensitive_main():
    # ① 幂等：产物存在即跳过
    if os.path.exists(OUTPUT_FILE):
        rprint(f"[yellow]⚠️ {OUTPUT_FILE} already exists, skipping.[/yellow]")
        return
    # ② 真正逻辑
    ...
    # ③ 写盘
    ...

if __name__ == '__main__':
    replace_sensitive_main()
```

> 📌 三条约定：**① 顶部 `sys.path.append` 指向项目根 ② 幂等检查在最前 ③ 提供 `__main__` 入口**。缺第③条就没法单步调试。

### 步骤 2：在 `st.py` 的编排函数里插入调用

打开 [`st.py`](../../st.py)，找到对应的编排函数（字幕阶段是 `process_text()`，配音阶段是 `process_audio()`），在正确位置插入：

```python
with st.spinner("替换敏感词中..."):
    step6_1_replace_sensitive.replace_sensitive_main()
```

⚠️ 注意 `process_text()` 里 `transcription_only` 有两条不同分支（`st.py:91-110`），确认你的步骤是否**只应在一个分支里跑**。

### 步骤 3：在 `imports_and_utils.py` 注册模块

[`st_components/imports_and_utils.py`](../../st_components/imports_and_utils.py) 的 `from core import (...)` 列表按注释分成了 5 组（Download & Transcribe / Text Processing / Subtitle Timeline / Audio Generation / Final Video Composition）。把你的模块加到对应组里——**这是最容易忘的一步**，忘了会在运行时 `NameError`。

### 步骤 4：（可选）加配置开关

若步骤需要开关：

```yaml
# Whether to replace sensitive words in subtitles
replace_sensitive: false
```

然后在模块里 `load_key('replace_sensitive')` 决定是否执行。规范见 [`../04-interfaces/01-配置文件与参数.md`](../04-interfaces/01-配置文件与参数.md)。

### 步骤 5：（可选）加 UI 控件

若要在侧边栏暴露开关，改 [`st_components/sidebar_setting.py`](../../st_components/sidebar_setting.py)，照抄同类 `st.checkbox` + `update_key` 的写法。

## 三、如果新步骤要改变"阶段完成"的判据

UI 用两个文件判断阶段是否完成：

| 阶段 | 判据 | 位置 |
| --- | --- | --- |
| 字幕完成 | `output/output_sub.mp4` 存在 | `st.py:12`、`:50` |
| 配音完成 | `output/output_dub.mp4` 存在 | `st.py:13`、`:133` |

若你的步骤加在**末尾**（阶段完成之后），UI 不会给你任何入口——需要同时改 `st.py` 的判据或新增一个区块。参考 [`../04-interfaces/02-Streamlit界面组件.md`](../04-interfaces/02-Streamlit界面组件.md)。

## 四、如果新步骤要"替换"而不是"插入"

替换某一步时，只需保证**产物契约不变**。举例：把 `step2` 换成别的 ASR，只要仍写出 `output/log/cleaned_chunks.xlsx`（列 `text`/`start`/`end`，且 `text` 值带双引号），后面的步骤完全不用改。

这体现了本项目的核心设计（磁盘即契约）：

```mermaid
flowchart LR
    A["上游步骤"] -->|"写 output/log/xxx.xlsx"| B["你的新步骤"]
    B -->|"写同路径同 schema"| C["下游步骤\n无需任何改动"]
```

⚠️ **双引号契约**：`save_results()` 写 `cleaned_chunks.xlsx` 时会把 `text` 包成 `f'"{x}"'`，下游统一用 `.str.strip('"').str.strip()` 剥离。若你替换了生产者，**要么保持这个怪癖，要么同时修改所有消费者**（grep `.strip('"')` 找到它们）。

## 五、验证清单

| 检查项 | 方法 |
| --- | --- |
| 幂等 | 连跑两次，第二次应打印"跳过"且产物 mtime 不变 |
| 单步可跑 | `python -m core.step6_1_replace_sensitive` |
| UI 连通 | 从页面点按钮跑完整阶段，确认不报 `NameError` |
| 幂等链完整 | 删掉你的产物，重跑，确认上游不会被重复执行（上游产物还在，应跳过） |
| 断点续跑 | 跑到一半 Ctrl+C，再点一次按钮，应从你的步骤继续（因为上游产物都在） |
