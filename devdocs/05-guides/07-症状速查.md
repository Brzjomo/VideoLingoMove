# 症状速查

> 用途：**症状 → 最可能的原因 → 怎么确认 → 怎么办**。
> 本文偏向"行为变了 / 为什么和我想的不一样"；按**报错字符串**检索请看 [`05-常见故障排查.md`](05-常见故障排查.md)；
> 缺陷根因与修复进度见 [`04-已知问题与技术债.md`](04-已知问题与技术债.md)。

## 一、先跑这四条命令

```bash
python installer.py --check # 环境体检；有错误时退出码为 1
python launch.py --no-log # 启动前预检（缺包/缺 ffmpeg/端口占用），只打印不启动
python -m unittest discover -s tests -v # 回归测试（12 个文件 / 242 例）
python -c "import torch; print(torch.__version__, torch.cuda.is_available)"
```

四条都通过仍出问题，再按下面的症状表定位。

> 环境说明：本分支用 `Install.bat`（uv）在项目内建 `.venv`，启动走 `OneKeyStart.bat`（**优先 `.venv`**，
> 回退旧的 conda 环境 `videolingo`）。旧 conda 环境是升级前的老栈（torch 2.1.2 / streamlit 1.38），
> **不能**用来跑本分支的 `st.py`。手工跑命令请用 `.venv\Scripts\python.exe`。

## 三、缓存相关的三个位置（最容易混）

| 位置 | 内容 | 键/失效条件 | 清理方式 |
| --- | --- | --- | --- |
| `.cache/asr/<key>/<part>.json` | 转录结果（`part` 为 `complete` 或 `f"{start:.2f}_{end:.2f}"`） | `transcription_cache.cache_key`：源媒体内容 + schema + whisperx/faster-whisper/demucs 版本 + `asr_engine`/model/language/demucs；火山再加 10 个参数。**不含**密钥、文件名、翻译设置 | 页面「清空转录缓存」/ `transcription_cache.clear_cache` / 删目录 |
| `output/log/asr_results/volcano_asr_*.json` | 火山引擎自己的二级缓存 | 文件名 + 起止时间匹配 | 页面「清空 ASR 结果缓存」 |
| `output/gpt_log/<log_title>.json` | LLM 调用缓存 | prompt + model + log_title | `ask_gpt(..., use_cache=False)` 或 `bypass_cache=True`；或删文件 |

> ⚠️ 前两者**故意分开**：`.cache/asr` 在 `output/` 之外，所以"归档到历史记录"不会让它失效
> （这是有意的 —— 不想因为清理产物就重复付费识别）。

## 四、怎么定位是哪一次改动引入的

```bash
git log --oneline -20 # 最近发生了什么
git log -S'<符号名>' --oneline -- <文件> # 某个符号/字符串是在哪次提交引入或删除的
git show <sha> # 看该次改动的完整内容与提交信息
git diff <sha>^ <sha> -- <文件> # 只看某个文件的净变化
```

想临时退回旧行为（不改分支）：

```bash
git revert <sha> # 撤销单个改动
git checkout <sha>^ -- <文件> # 只把某个文件退回上一版
```

## 五、验证边界（排错时请留意）

- **回归测试是可跑的**：`python -m unittest discover -s tests -v` → 12 个文件 / 242 例；
 多数用例是纯逻辑 + `FakeTorch` 桩，不需要 torch/spacy/网络。少数需要 ffmpeg/ffprobe 的用例会自动跳过。
- **不容易在本机复现的部分**：Streamlit 页面的实际渲染（进度面板、暂停/停止按钮、字幕长度面板、模型搜索框）；
 火山 ASR 的真实请求链路（需凭据且产生费用）；macOS/Linux 上的烧录字体效果。
- 遇到与"环境"相关的报错，先跑 `python installer.py --check --smoke`，它会逐个 import
 `whisperx` / `ctranslate2` / `faster_whisper` / `pyannote.audio` / `demucs.api` / `torchcodec.decoders` /
 `spacy` / `streamlit`，直接指出是哪一个装不上。
